# V5.9 行为金融补全：从有限理性到有限套利

## 现状

行为金融目前只有 `/s/behavior-microstructure` 一个实验室（V4.7），行为侧仅 4 个模型：双曲贴现、DSSW 噪声交易者 IRF、过度自信换手率、处置效应模拟；其余篇幅都是市场微观结构（Kyle / Glosten-Milgrom / Roll / Almgren-Chriss / Amihud）。报告中的前景理论、信念形成模型（BSV / DHS / HS）、有限套利约束、投资者情绪与异象、行为公司金融、行为宏观金融均无对应工具，也没有理论导读页——这与资产定价、计量、时序、组合、衍生品、风险各版块"实验室 + 理论导读"的双件套结构不一致。

## 目标

按前几个版块的同一范式补齐行为金融：新增一个 8 个交互实验的行为金融实验室，加一篇结构化理论导读，并把二者接入统一导航与版本体系。

## 一、新增模型层 `src/lib/quant/behaviorFinance.ts`（纯函数 + 单测）

1. **累积前景理论 CPT**：价值函数 v(x)、Tversky-Kahneman 概率权重 w(p)、赌局的 CPT 值与确定性等价；对比期望效用基准，输出四重风险态度矩阵。
2. **短视损失厌恶（Benartzi-Thaler）**：给定评估频率与损失厌恶 λ，求解使投资者对股/债无差异的隐含股权溢价，解释股权溢价之谜。
3. **BSV 信念模型**：保守主义 + 代表性的两状态制度切换，生成短期反应不足、长期过度反应的累计异常收益路径。
4. **DHS 过度自信 + 自我归因**：私有信号过度反应 → 公开信息延迟纠偏，产生动量后接反转的脉冲响应。
5. **HS 信息缓慢扩散**：新闻观察者 / 动量交易者两类主体，扩散速度与动量交易者规模决定动量强度与过冲。
6. **有限套利约束**：噪声交易者风险 + 保证金/赎回约束下的套利者最优头寸与错价收敛半衰期；输出"被迫平仓"临界点。
7. **投资者情绪与截面异象（Baker-Wurgler 式）**：情绪指数分组下难以估值/难以套利股票的收益差，生成情绪高低期的组合收益对比。
8. **行为公司金融**：管理者过度自信下的投资—现金流敏感性，与市场时机（择时发行）对资本结构的路径影响。

每个模型配 `src/lib/quant/__tests__/behaviorFinance.test.ts` 的极限/单调性断言（如 λ=1、β=1、情绪=0 时退化到理性基准）。
